# Задание: написать уроки «Биологии AI»

Самодостаточная инструкция для агента (в том числе облачного). Владельцу вопросов не задавать — всё нужное ниже и в репозитории.

## Контекст

Это Hugo-сайт «Биология AI»: школьная биология 5–11 класса, ОГЭ и ЕГЭ, биоинформатика и ML. Программа — `PROGRAM.md` и `data/program.yaml`. Для каждого урока уже есть файл-заготовка в `content/<раздел>/NNN-slug.md` с `placeholders: true`. Твоя задача — заменить заготовку настоящим уроком.

**Эталон качества — `content/obshchaya-biologiya/088-organoidy-kletki.md`.** Прочитай его целиком перед началом: структура, тон, длина, оформление картинок, задания, блок «Биология будущего». Новые уроки должны быть не хуже.

**Мастер-инструкция — `LESSON-PROMPT.md`.** Прочитай целиком. Все требования оттуда обязательны.

## Какие уроки писать

Список — в разделе «Текущая пачка» в конце файла (или в сообщении, которым тебя запустили). Пиши их по одному: закончил урок — проверил — следующий.

## Как оформить файл урока

1. Открой заготовку `content/<раздел>/NNN-slug.md`. **Имя файла и slug не меняй.**
2. Замени содержимое целиком. Frontmatter — как у урока 088:
   - `title`, `seo_title`, `description`, `seo_description` (≤160 знаков, начинается с поискового запроса);
   - `date` и `lastmod` — сегодняшняя дата (не будущая, иначе Hugo не опубликует);
   - `grade`, `category`, `emoji`, `level: "school"` (или `"exam"`, `"bio-it"`), `difficulty`, `duration`;
   - `lesson_number: NNN` и `weight: NNN`;
   - `keywords` (6–9), `prerequisites` и `next_lesson` — полные slug соседних уроков из `data/program.yaml`;
   - **строки `placeholders: true` быть не должно.**
3. Ссылки на другие уроки — от корня: `[Органоиды клетки](/obshchaya-biologiya/088-organoidy-kletki/)`. Ссылаться можно на любые уроки программы, даже ещё не написанные.

## Картинки (обязательно 4–8 на урок)

Инструмент — `scripts/commons.py` (Wikimedia Commons, только свободные лицензии):

```bash
pip install pillow requests          # один раз
python scripts/commons.py search "mitosis stages ru" --n 8
python scripts/commons.py get 095 mitoz-fazy "File:Название файла.svg"
```

- Сначала ищи версии с **русскими подписями** (`... ru`, русские слова в запросе), потом без подписей, потом английские (переводи подписи в `caption`).
- `get` кладёт файл в `static/images/lessons/NNN/имя.webp` и печатает credit.
- **Каждую скачанную картинку открой и посмотри глазами** (инструментом чтения изображений). Commons иногда отдаёт пустые схемы без рисунка, только с подписями, или не ту картинку. Такие удаляй и ищи замену. Гравюры и фото тяжелее 250 КБ ужимай (ширина 800 px).
- Вставка — шорткодом `figure`, как в уроке 088: `src`, `alt`, `caption`, `credit`. **Credit пиши аккуратно вручную:** автор, `[Wikimedia Commons](ссылка на страницу файла)`, лицензия. Без переносов строк и обрывков, которые иногда выдаёт скрипт.
- **Скачивай строго по одной картинке, не запускай несколько копий скрипта параллельно** — Commons режет частые запросы, и параллельные загрузки только всё тормозят. Скрипт сам выдерживает паузы и повторяет запрос.

## Точность

- Факты, цифры, годы, имена — только те, в которых уверен. Сомневаешься — не пиши цифру или сформулируй осторожно.
- Терминология — по школьной программе. Где учебники расходятся, так и напиши.
- Генетические задачи и расчёты пересчитай дважды.
- Блок «Биология будущего» — только реальные проекты и технологии.

## Проверка перед коммитом

1. Если в окружении есть `hugo`: `hugo --quiet` — сборка без ошибок.
2. Во frontmatter нет `placeholders`, дата не в будущем.
3. Все картинки из урока лежат в `static/images/lessons/NNN/` и просмотрены.
4. Ровно 30 заданий, у каждого `{{< solution >}}`.
5. Нет управляющих символов в тексте (особенно испорченных `\a`, `\b` в формулах LaTeX).

## Git

- Работай в ветке, которую тебе выдали (или создай `lessons/<краткое-имя-пачки>`).
- Один коммит на урок: `Урок NNN: <название>`.
- **Не меняй** шаблоны (`layouts/`), `hugo.toml`, `PROGRAM.md`, `data/program.yaml`, `.github/` и чужие уроки.
- `data/image_credits.json` дописывается скриптом — его коммить вместе с уроком.
- В конце — push ветки и короткий отчёт: какие уроки готовы, сколько картинок, что вызвало сомнения.
